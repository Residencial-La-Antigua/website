# Residencial La Antigua — Plataforma Comunitaria

Este es el sitio web de nuestra comunidad, creado para ayudar a los vecinos a organizarse en torno a la siembra de árboles, la coordinación de voluntariado y la vida del vecindario.

## Acerca de

El vecindario mantiene cuadrillas de voluntarios que siembran, podan y patrullan, y hasta ahora ha coordinado este trabajo de forma manual. Esta plataforma reúne esa coordinación en una sola herramienta compartida y propiedad de la comunidad: un inventario de plantas/árboles, inscripciones de voluntarios, un directorio de vecinos, un calendario de eventos y seguimiento de donaciones.

El proyecto es de código abierto para que otros vecindarios con necesidades de coordinación similares puedan adaptarlo para su propia comunidad.

## Módulos de funcionalidades

El conjunto de funcionalidades se ha organizado en 7 módulos funcionales:

| Módulo                                       | Incluye                                                                                                                          |
| -------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **Identidad y Acceso**                       | Cuentas de vecinos, registro aprobado por administrador, directorio de vecinos                                                   |
| **Plantas e Inventario**                     | Catálogo de plantas, base de datos del inventario de siembra, registro fotográfico de aceras, formulario de solicitud de plantas |
| **Cuadrillas y Coordinación de Voluntarios** | Inscripciones a jornadas/patrullajes, roles de cuadrilla, lista de equipo, chat de cuadrilla, bitácora de actividad              |
| **Comunicación Comunitaria**                 | Chat de vecinos, formularios de contacto, integración con WhatsApp                                                               |
| **Contenido, Medios y Concientización**      | Galería de fotos, recursos educativos, noticias, acerca de                                                                       |
| **Eventos y Programación**                   | Calendario anual (eventos únicos y recurrentes)                                                                                  |
| **Donaciones y Recursos**                    | Donaciones (dinero o plantas), lista de deseos de donaciones                                                                     |

## Progreso actual

- **Autenticación de vecinos:** registro de cuentas, aprobación por administrador antes de poder iniciar sesión, e inicio/cierre de sesión.
- **Información básica:** páginas de referencia con teléfonos importantes, recolección de basura y reciclaje, y desechos no tradicionales.
- **Calendario de eventos:** vista mensual navegable por mes y año, creación y edición de eventos únicos o recurrentes (diarios, semanales o mensuales) por parte de administradores, y confirmación o cancelación de asistencia por parte de los vecinos, con historial de confirmaciones consultable desde el panel de administración.
